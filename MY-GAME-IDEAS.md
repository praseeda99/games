# My Game Ideas

Copy the template below for each game idea, fill in what you can, and tell Claude to build it.
Skip anything you don't care about. Even one sentence is enough to start.
You can also drop pictures or sketches into the `designs/` folder and mention them.

---

## Game name:

**What's it about? (1-2 sentences)**


**How do you play? (tap / swipe / drag / tilt / hold?)**


**How do you win or lose?**


**What does it look like? (colors, style, vibe, characters)**


**Sounds / music?**


**Single player or with friends?**


**Anything else? (power-ups, levels, bosses, secret stuff...)**


---

## Changes to existing games

Want to tweak something? Write it here, like:
- Neon Dodge: make the player a cat instead of a ball
- Snake: add a mode where walls wrap around
